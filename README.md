# MyWorld3D

Top-down 3D procedural city simulation. Built with Vite, TypeScript, Three.js, React Three Fiber.

## Run

    npm install
    npm run dev

## Scripts

- `npm run build`: typecheck and production build
- `npm test`: unit tests (vitest)
