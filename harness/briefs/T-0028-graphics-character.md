- **Goal:** the walk gets human mechanics on top of today's thigh / knee / arm / elbow rotation and vertical bob (`applyRig` in `rigShaderGlsl.ts`, now 264 lines: do NOT grow it past 350, put the new terms in a new generated file the way `idleMath.ts` does: TS mirror + `gaitGlsl()` built from the same constants). Terms, for WALKING people only (`walk = 1`); idle, chat and sit stay exactly as T-0027 left them:
  1. Pelvis yaw and side sway: pelvis (part 0 pelvis region and the legs' hip attachment) rotates about the vertical axis by a few degrees at step rate and sways sideways a few mm over the stance leg.
  2. Shoulder counter-rotation: the torso, arms and head twist opposite to the pelvis by a few degrees (arms swing is already there; this adds the torso twist about the vertical axis through the spine).
  3. Ankle flexion with heel strike and toe-off: the foot (shoe vertices of the shin parts 3 and 4: region FIXED, low y; the shoe has no own part id, so identify foot vertices by `p.y` below the ankle height plus the part id, or add a part id only if you must keep part ids/regions/pivots otherwise intact because shared materials depend on them) rotates about the ankle pivot: toe up at heel strike (about 10 to 15 degrees), plantar flex at toe-off (about 20 degrees), so the planted foot rolls instead of sliding.
  4. Head stabilisation: the head partly cancels the vertical bob (counter offset a fraction of `bob`) and the twist.
  - All amplitudes scale with speed (omega) and age group (child larger bob already in `aGait2`; elders smaller): derive from `amp` (`aGait.w`) and the existing per-instance multipliers, no new per-instance attributes. Designer amplitudes as knobs in `src/config/tuning/trafficLife.ts`: `gaitPelvisYawDeg` (3), `gaitPelvisSwayMm` (8), `gaitTorsoTwistDeg` (4), `gaitAnkleDeg` (12), `gaitHeadStabilise` (0.6); each with a doc line, a parity entry in `tests/tuningParity.test.ts`, a row in `docs/TUNING.md` with the meaningful range (be explicit; shader gains must not secretly multiply the knob: if you add a gain, say it in the TUNING row). Uniform vec/float like `uIdle`; update `createPeopleUniforms`/`typeUniforms` the same way `uIdle` was done and bind it for far, near and depth.
