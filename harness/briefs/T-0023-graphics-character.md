# Brief: T-0023 (graphics-character)

- **Task id:** T-0023-ped-near-model-detail
- **Owner:** graphics-character
- **Reviewer:** reviewer (read-only subagent)
- **Goal:** the NEAR mesh set (T-0022) uses a smoother, more detailed body model; the FAR set keeps today's model unchanged (same geometry, same triangle count, so far-view cost and look do not change). Procedural only.
- **Design (lead's, change with a reason):**
  - `buildShape(kind, sex, detail)` and `buildPerson(kind, detail)` with `detail: 'far' | 'near'`. `'far'` output must be byte-identical to today's (test it by comparing triangle counts and a position checksum with the old behaviour before you change anything: record them first).
  - Near model: 8-sided tapered limbs with SMOOTH normals (add a `limb`/smooth-frustum primitive to `RigBuilder`; the existing `box` stays for the far model), rounder torso (8 to 10 sided with shoulders and a waist taper), a neck, head ellipsoid about 12x8, hand block with a thumb, shaped shoes (heel and toe cap), hair cap and styles with a few more segments. Keep every part id, region, pivot and the vertex ORDER independent of sex (male and female built from the same call sequence; morph attributes aMorph and aMorphN are computed from the two). The near model must have the SAME pivots (hip, shoulder, neck, seatDrop, headTop) as the far one, so the shared materials and uniforms stay valid. Check what `createPersonMaterials` reads from the model and share one material per age group (built from the far model), or build near materials only if a uniform really differs.
  - Seams: hide joints by overlap (a limb end slightly inside the next part), never by two equal planes. No coplanar geometry. Keep eye, brow, mouth quads as today (T-0024 replaces them with a shader face), but do not add new near-coplanar quads.
  - Budget: near 900 to 1400 triangles per person per age group (all parts including hidden hair styles, garments, beard); far 350 to 480 unchanged. Update the header comments and `tests/people.test.ts` ranges per detail level (do not loosen the far range). Report the exact numbers per age group.
  - Wiring: `peopleMeshes.ts` builds `modelsFar` and `modelsNear`; the far set uses far geometry, the near set uses near geometry (T-0022 used `shareGeometries`: the near set now owns its own geometry; adapt `createPersonSet`). `models` public field: keep `models.person` as the far models, add `models.personNear`. Dispose both. Keep peopleMeshes.ts under 350 lines (it is 325): move code out if needed.
  - Cost check: near cap is `nearMaxInstances` 64 per group, so worst case extra triangles in a frame is about `64 * 4 groups * (near - far)` tris in the main pass plus the shadow pass; compute and write the number into the handbook next to the T-0020 baseline. Measure `npm run smoke` and `npm run smoke:closeup` (populated near meshes) and report draw calls and triangles with near people present, which T-0022 did not measure.
  - `tests/smoke/closeup.mjs` / `closeupHook.mjs` may need nothing; look at one near close-up PNG (3 m adult) by eye and say what you see (smoothness, seams, holes).
